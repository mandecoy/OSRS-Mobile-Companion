# OSRS Companion Tool

Free, open-source Android companion app for Old School RuneScape Mobile.

## Current build — 0.2.0

- Custom AFK timers with separate minute and second fields
- Timer notifications that can fire after the app is closed
- Timer restoration after reboot
- Farming and run timer presets
- Four customizable quick widgets across the top row
- Pin any custom timer value directly into a quick-widget slot
- Puzzle Box screenshot solver access with 5-step workflow
- Light Box solver
- Grand Exchange prices
- OSRS Wiki
- Wise Old Man
- Shooting Stars tracker
- Skill calculators
- RuneScape Wiki DPS calculator
- Quest, diary, and clue references
- OSRS-inspired visual icons and gnome launcher icon

## APK

GitHub Actions builds the Android APK automatically. Open the Actions tab, choose the latest successful Android APK run, and download the artifact.

## Privacy

The app has no account system and no analytics. Timer and quick-widget data is stored locally. Embedded websites are third-party services and have their own policies.
