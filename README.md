# OSRS Mobile Companion

Free, open-source Android companion app for Old School RuneScape Mobile.

## Current public build

This repository now contains the first buildable Android foundation for the app.

Included now:

- Custom AFK timers from 1 second to 30 minutes
- Android notifications that can fire after the app is closed
- Timer restoration after a phone reboot
- Farming and run timer presets
- Two customizable quick actions on the home screen
- Puzzle Box screenshot-solver access inside the app
- Light Box solver access inside the app
- Grand Exchange prices
- OSRS Wiki
- Wise Old Man
- OSRS Portal Shooting Stars tracker
- OldSchool.Tools skill calculators
- Quest, diary, and clue reference sections
- Old-school-inspired stone interface with large buttons

Puzzle and light-box solving currently use embedded free browser tools while the native on-device solvers are developed.

## APK

GitHub Actions builds the Android APK automatically. Open the Actions tab, choose the latest successful Android APK run, and download the OSRS-Mobile-Companion-debug artifact.

## Privacy

The app has no account system and no analytics. Timer data and quick-action preferences are stored locally. Embedded websites are third-party services and have their own privacy policies.
